# 咪蒙文章结构模板

## 模板零：SCQA + 咪蒙三段式（最核心的内容骨架）

> 来源：咪蒙自我剖析文档。

### SCQA 模型

```
S（Situation 场景/情景）
- 描述一个读者熟悉的场景，这个场景往往与读者息息相关或是一贯痛点。
- 目标：让读者一看就觉得「说的就是我」。

C（Conflict 冲突）
- 点出场景里的核心矛盾，亟待解决。
- 目标：制造张力，让读者想知道下文。

Q（Question 问题）
- 面对冲突，抛出「到底该怎么办？」

A（Answer 答案/解决方案）
- 给出解决方案或鲜明态度。
- 目标：让读者获得情绪释放或实用价值。
```

### 咪蒙三段式（最推荐操作）

```
1. 开门见山亮出观点
   - 一句话站队，不中立。

2. 用极端/完整例子来解释观点
   - 例子占文章 4/5 篇幅，要有背景、细节、人物刻画。
   - 或者 4-5 个小例子层层递进。

3. 来点干货压压惊
   - 短句子 + 亲民故事 + 段子 + 鸡汤金句 + 情绪疏导
   - 给出可执行建议或态度升华。
```

## 模板一：观点故事混合型（最常用）

适用：情感、职场、社会观察、两性。

```
# 标题：13-20字，带「你/我/我们」，情绪明确

## 开头钩子（1-3句话）
- 第一句：短促、有冲突、扎痛点。
- 第二句：过渡到个人或身边故事。

## 亮明观点（1句话站队）
- 不要中立，直接说「我觉得」「说白了」。

## 故事/案例 1（自己或身边人）
- 有具体场景、对话、细节。
- 情绪递进：委屈→愤怒→醒悟。

## 故事/案例 2（对比或递进）
- 可以是反例，也可以是另一个角度的故事。

## 金句区（2-3句）
- 短、有颠覆感、带感叹号。

## 方法论/观点升华（告诉读者怎么做）
- 给出 1-3 条可执行的建议或态度。

## 结尾 CTA
- 金句收尾 + 互动/转发/评论引导。
```

## 模板二：清单干货型

适用：职场经验、书单、影单、生活技巧、情商/沟通。

```
# 标题：数字 + 价值感 + 「你/我」

## 开头（200字以内）
- 先抛一个痛点或炫耀一下自己的积累。
- 让读者觉得「这东西值得收藏」。

## 清单条目 1
### 小标题：一句话点出核心
- 解释 + 小故事/例子。
- 一句金句或反常识结论。

## 清单条目 2
（同上）

## 清单条目 3-N
（同上）

## 结尾
- 总结：「做到这几点，你就能……」
- 福利/互动：留言、转发、点赞抽奖。
```

## 模板三：情绪 rant 型

适用：吐槽、社会热点、反常识观点、解气文。

```
# 标题：直接挑衅/否定/质问

## 开头（点燃情绪）
- 点出一个让人愤怒或无奈的场景。
- 用第二人称「你」让读者立刻代入。

## 第一层吐槽
- 短句、排比、反问。
- 情绪：从压抑到爆发。

## 第二层吐槽
- 举一个典型例子，细节越具体越好。

## 金句爆发
- 3-5 个短句连击。

## 转折：其实我想说的是……
- 把吐槽升华为观点或态度。

## 结尾
- 一句态度鲜明的收尾。
- CTA：「同意的转起」「你遇到过吗？留言」。
```

## 模板四：影视/书评反常识型

适用：影评、剧评、书单。

```
# 标题：电影名/书名 + 反常识角度

## 开头（200字以内）
- 一句话评价，不剧透但勾起好奇。
- 或者用一个反常识观点开局。

## 主体：3-5 个片段/角度
- 每个角度配一句犀利点评。
- 多用短句、比喻、段子。

## 金句区
- 把电影的普世价值点出来。

## 结尾
- 推荐语 + 互动（你看了吗？）。
```

---

## 通用节奏技巧

- 每 300-500 字需要一个「情绪小高峰」：金句、段子、反问、粗口（轻量）。
- 段落尽量短，手机屏上 2-4 行为一段。
- 重要词汇可一字一顿：「太。讨。厌。了。」
- 善用括号吐槽：「（是的，我就是这么没尊严）」。
- 善用「PS/再PS」增加聊天感。
