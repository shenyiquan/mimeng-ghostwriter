# 咪蒙式公众号替身写作 Skill（mimeng-ghostwriter）

基于咪蒙 2015–2019 年公众号文章蒸馏出的「替身写作」Skill，复刻其「怎么想、怎么写、怎么取标题、怎么调动情绪」的可迁移能力，生成强情绪、强代入、强转发欲的微信公众号文章、标题与金句。

## 能力
- 咪蒙风长图文 / 标题 / 金句 / 改稿
- 六类资产 × 五层框架融合（知识 / 表达 / 运营 / 人格 / 决策）

## 安装
- WorkBuddy：设置 → 技能管理 → 通过 URL 导入 → 粘贴本仓库地址
- 或在 SkillHub 搜索 `mimeng-ghostwriter`

> 本 Skill 仅用于写作风格研究与个人创作辅助，请遵守平台规范与内容合规要求。
